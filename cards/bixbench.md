# BixBench: a Comprehensive Benchmark for LLM-based Agents in Computational Biology

给智能体生物数据和空白 Notebook，让它完成多步分析并回答问题，再分别用开放回答和选择题设置评价结果。

- 作者：Ludovico Mitchener, Jon M Laurent, Alex Andonian, Benjamin Tenmann, Siddharth Narayanan, Geemi P Wellawatte, Andrew White, Lorenzo Sani, Samuel G Rodriques
- 年份：2025 · 类型：benchmark
- 主题：AI4S Agent 评测
- [原文](https://arxiv.org/abs/2503.00096v3) · 收录：2026-11-11 · 更新：2026-11-11

- 子类：科学领域基准

归类依据（知识库分析）：任务直接基于真实生物信息学数据和分析笔记本，测从探索文件、编写分析到解释结果的端到端能力；不是按是否复现某一份参考程序评分。

## 研究问题

会写代码或回答生物知识题，并不意味着能独立处理真实生物数据。BixBench 检查智能体能否在信息较少、工具自由的环境里探索数据、选择分析并解释结果。本卡使用 2025 年 10 月 v3，任务规模和成绩与早期摘要版本不同。

证据：e1

## 原有做法与缺口

真实分析常需多步计算、专门软件和对问题的解释，固定函数补全或知识选择题覆盖不了这些过程。作者从专家分析轨迹构建任务，主要采用开放回答，避免在分析开始前直接给出候选答案。

证据：e1, e2

## 核心方法

专家先建立包含问题、数据和分析 Notebook 的胶囊，模型生成候选问题，再由专家修改、审核和去重。测试时只给智能体数据、问题和空白 Notebook。基于 Aviary 的智能体可列目录、编辑执行单元格和提交答案；开放回答由 Claude 3.5 Sonnet 对照标答做二元评判。选择题模式在分析结束后另给模型完整 Notebook、回答与选项，不能与开放回答混算。

证据：e1, e2

## 一个具体例子

附录示例要求分析不同菌株的差异表达：回答某菌株的差异基因有多少比例也在另一菌株显著，以及 DESeq 分析中多少基因的 dispersion 小于 1e-5。智能体必须找到数据、组织 R 或 Python 分析，最后提交各问题的短答案。题目没有向它公开专家原来的 Notebook，最终是否正确仍由对应标答与评审决定。

证据：e5, e2

## 输入与产出

v3 包含 61 个真实分析胶囊、205 道问题。输入文件格式和目录结构不统一；预配置 Docker 环境提供常用 Python、R 和 Bash 工具。输出既有保存的分析 Notebook，也有按问题提交的答案；运行轨迹能供诊断，但开放回答主指标是答案正确率。

证据：e1, e2

## 关键结果与实验条件

每个胶囊并行运行五次；两种模型和有无图像两种设置共得到 1,220 条轨迹。开放回答中 Claude 3.5 Sonnet 约 21%，GPT-4o 约 15%。选择题允许拒答时接近随机，去掉拒答选项后分数上升，但未显示超越不看分析 Notebook 的纯模型回答基线；五次多数投票也没有带来明显改善。这不能读成“模型凭实际分析已完成四成任务”。

证据：e2, e3

## 主要贡献

论文提供经过专家整理的生物分析场景、开放回答评价和支持多语言执行的 Notebook 智能体环境。开放回答、拒答、投票与图像消融放在同一任务上比较，帮助识别候选选项和常识猜测对成绩的影响。

证据：e1, e2, e3

## 局限与适用边界

只测了两类当时的模型，没有独立专家在相同设置下完成任务的人类基线。工作流和数据类型覆盖也不完整。开放回答仍由模型对照参考答案判断，因此自由分析空间不等于评分已经容纳所有合理方法或结论；应结合后续对基准材料的独立审计阅读。

证据：e4, e2

## 成本与复现条件

复现需要数据胶囊、预构建容器、Notebook 执行服务、智能体模型和评审模型。五次采样与图像对照会成倍增加运行次数，单元格修改后重跑完整 Notebook 也可能重复计算。论文没有报告可直接套用到任意胶囊和模型的统一 API 费用或总 GPU 预算。

证据：e2, e3

## 与研究主题的关系

知识库分析：它直接研究生物数据分析智能体，比孤立的知识问答更贴近工作流。与 BenchGuard 一起阅读，可以区分实际分析能力不足和参考答案、题目或评审规则的问题。

研究关联分析；未作为论文结论。
