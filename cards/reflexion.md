# Reflexion: Language Agents with Verbal Reinforcement Learning

把失败经历写成几条给自己的提醒，下次尝试时带上这些记忆；反思有帮助，但也受测试质量和搜索能力限制。

- 作者：Noah Shinn, Federico Cassano, Edward Berman, Ashwin Gopinath, Karthik Narasimhan, Shunyu Yao
- 年份：2023 · 类型：framework
- 主题：RSI · 递归自我改进
- [原文](https://arxiv.org/abs/2303.11366v4) · 收录：2026-11-11 · 更新：2026-11-11

- 子类：代码与软件工程 / 数学与推理 / 工具交互与控制 / 编程与程序优化 / 改进流程保持固定

归类依据（知识库分析）：使用固定模型与反思流程更新文字记忆，在编码、问答和环境交互中重试；未让演化后的改进器继续修改自身改进规则。

## 递归闭环与证据边界（知识库分析）

- 证据状态：固定改进流程下的文字记忆更新

- 下一轮职责：下一轮 Actor 读取此前生成的反思文字重新完成同一道任务；生成反思的模块及循环规则本身没有随实验演化。

- 固定组件：语言模型权重、Actor/Evaluator/反思模块的组织方式、提示模板与记忆窗口由实验者固定。

- 改进能力证据：报告重复尝试后的任务成绩和消融实验，没有独立测量演化后的改进器在新改进任务上的能力或自加速。

## 研究问题

智能体做错后，如果只是重新采样，可能继续犯同样的错误。论文希望在不训练模型权重的情况下，把失败反馈变成下一次能用上的经验，并测试这种方法是否适用于操作环境、问答和写代码。

证据：e1, e2, e3

## 原有做法与缺口

执行器通常只给出成功或失败，模型需要进一步判断该改哪里。保留整段旧轨迹也不一定能提炼出有效经验。作者把执行任务、评价结果和写反思分开，并用消融检查反思文字是否比仅重试或保留经历更有用。

证据：e1, e3, e4

## 核心方法

Actor 完成一次任务，评价器给出反馈，反思模块结合轨迹、反馈和旧记忆写下经验，再让 Actor 带着记忆重试。记忆通常只保留最近1–3条。ALFWorld 使用环境成功信号及重复动作、步数启发式；问答采用答案精确匹配；编程用自生成测试反馈。三个模块可以调用同一基础模型的不同提示，不意味着训练了三个模型。

证据：e1, e2, e3

## 一个具体例子

附录中的问题问两位作家的共同职业。首次回答把“小说家”和“编剧”都选上，收到错误信号后，模型反思自己把各自的职业误当成交集；下轮回答缩为“小说家”。反馈只告诉它答错了，并没有直接提供正确答案。这个例子展示文字记忆如何影响重试，不证明反思准确复述了内部推理。

证据：e6

## 输入与产出

输入是任务说明、环境观察或函数签名，以及此前尝试、评价反馈和反思记忆。输出包括动作轨迹、答案或代码，另有给下轮使用的文字经验。编程测试最多采6条有效测试，记忆保留1条；最终成绩用独立于自生成测试的基准检查。

证据：e1, e2, e3

## 关键结果与实验条件

在134个 ALFWorld 环境中，启发式反馈版本经过最多12次尝试累计解决130个。GPT-4 编程实验的 HumanEval Python 成绩从80.1%到91.0%，但 MBPP Python 从80.1%降到77.1%；这里的 pass@1 是内部多次修订后提交一个答案，并非只调用一次模型。最难的50道 HumanEval Rust 题上，完整方法为68%，只保留自生成测试为60%，去掉测试为52%。

证据：e2, e3, e4

## 主要贡献

论文给出不改权重的经验积累流程，并把反馈质量纳入分析。MBPP 的自生成测试会让约16.3%的“内部测试通过”提交在最终检查中失败，HumanEval 对应约1.4%；因此多写反思并不能弥补错误的成功判定。

证据：e1, e4

## 局限与适用边界

收益不普遍：100个 WebShop 任务中，四轮后未见明显改进，作者观察到反思难以带来足够多样的新搜索；较弱的 starchat-beta 在 HumanEval 上也没有提升。记忆窗口有限、自生成测试可能误判，重复做同一道题的提高不能直接等同于对新任务泛化，也不是递归改进能力增强的证据。

证据：e4, e5, e7

## 成本与复现条件

不需要梯度训练，但每次失败会增加执行、评价和反思调用。ALFWorld 最多12次尝试，问答在连续三次失败后停止，编程还要生成并执行测试。复现需要对应环境、检索接口或语言执行器；论文没有给出统一的整套实验 API 费用。

证据：e2, e3, e8

## 与研究主题的关系

知识库分析：它适合作为“反思能否帮助改进”的基础对照。改变的是任务记忆，改进流程本身固定；与 SICA、DGM 等继续使用演化后 Agent 的工作比较时，应分开讨论记忆带来的任务收益和改进机制的演化。

研究关联分析；未作为论文结论。
