# A Self-Improving Coding Agent

让表现较好的编码智能体继续修改自身工具和工作流，以任务成绩、时间和费用共同选择下一轮版本。

- 作者：Maxime Robeyns, Martin Szummer, Laurence Aitchison
- 年份：2025 · 类型：method
- 主题：RSI · 递归自我改进
- [原文](https://arxiv.org/abs/2504.15228v2) · 收录：2026-11-11 · 更新：2026-11-11

- 子类：Agent 与代码自改

归类依据（知识库分析）：从历史版本中选择效用最高的 Agent 来修改自己的完整 Python 实现，演化版本实际充当下一轮元智能体；主要实验支持特定预算下的任务表现变化，没有独立证明持续自加速。

## 递归闭环与证据边界（知识库分析）

- 证据状态：演化后的 Agent 参与后续自改

- 下一轮职责：每轮从包含已修改版本的档案选择效用最高者，让它检查档案并修改自身 Python 代码，生成下一候选。

- 固定组件：基础语言模型权重、外部基准集、效用公式和选择循环由实验者固定，不随这条主实验更新。

- 改进能力证据：同一批任务上的实测效用和编码成绩有所提高；没有将改进器在独立留出改进任务上的效率与任务能力分离检验，也没有证明长期自加速。

## 研究问题

语言模型要做软件工程，需要代码组织调用、工具和上下文。SICA 研究这些外层程序能否由智能体自己修改，而且让改进后的版本承担后续修改，而不是永远由一个固定元智能体设计别的智能体。

证据：e1

## 原有做法与缺口

人工设计框架靠不断试错；ADAS 等方法虽自动搜索智能体设计，元智能体本身仍固定。作者希望合并任务执行者与改进者，但编码成绩变好能否进一步带来更强的改进能力，仍是需要单独验证的问题。

证据：e1

## 核心方法

系统保存历史 Agent 及其测试结果。每轮选择效用最高的版本，让它查看档案、提出修改并编辑完整 Python 代码，再测候选并写回档案。效用由成绩、费用和耗时加权，权重分别为 0.5、0.25、0.25；费用项在每题10美元归一化上限截断，时间项以300秒归一化，超时后效用再乘0.5。基础模型不做权重训练。

证据：e1, e2

## 一个具体例子

初始智能体只能整文件覆盖，随后写出 diff 和范围编辑工具，减少冗余输出。第9轮加入 AST 符号定位器，以解析 Python 代码快速找到定义。这个改动对导航任务有帮助，也表明改进可能来自工具效率与测试集结构，而非底座模型推理能力增长。

证据：e4

## 输入与产出

输入是可修改的 Agent 代码、历史档案和固定评测任务。主实验从 SWE-Bench Verified 与 LiveCodeBench 各固定随机抽取50题，还使用文件编辑和符号定位的合成任务。输出是新的 Agent 程序及各任务成绩、费用和时间记录；不是训练后的新语言模型。

证据：e1, e3

## 关键结果与实验条件

多数模块使用 Claude 3.5 Sonnet v2，推理子智能体使用 o3-mini。表1中 SWE-Bench 子集从初始0.17升到第14轮0.53，第15轮为0.51，过程并非每轮都提高；LiveCodeBench 从0.65到第15轮0.71。另一组 AIME 2024 与 GPQA Diamond 实验提升有限，复杂框架未必胜过已经很强的推理模型。

证据：e3, e5

## 主要贡献

SICA 提供可以修改完整代码库的自指编码智能体，并展示演化后的同类 Agent 可继续承担下一轮开发。它把性能和资源使用一起纳入版本选择，还公开初始工具、监督器、提示词与修改轨迹，便于研究框架层面的学习。

证据：e1, e2

## 局限与适用边界

结果来自较小、反复使用的固定任务集，不能直接外推整个 SWE-Bench 或留出任务。作者指出新想法会受早期建议影响，坏方向可能形成路径依赖；五分钟超时也压低初始成绩，使早期提升较多来自加速编辑。符号任务还存在部分目标指向未安装库的数据质量问题。

证据：e3, e5

## 成本与复现条件

15轮主实验的模型 API 总费用约7,000美元，包含生成改动和反复评测；不能用表1平均每道测试题的约几美元代替整条改进流程成本。系统还需要代码执行、仓库环境、模型服务和定期运行的监督器，全文中的可观察日志不是对后续系统安全性的充分保证。

证据：e2, e3, e5

## 与研究主题的关系

知识库分析：它直接符合演化 Agent 继续自改的结构条件，可与 DGM 的开放档案探索、AIDE² 的独立后续改进检验比较。当前证据更适合支持框架自修改与受限任务提升，不能直接作为无限递归或持续加速的证明。

研究关联分析；未作为论文结论。
