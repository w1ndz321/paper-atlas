# Measuring Faithfulness in Chain-of-Thought Reasoning

截断或改错模型写出的思维链，检查答案是否随之变化，并区分推理有用、模型依赖推理和解释忠实这几件事。

归类依据（知识库分析）：通过截断、改错、改写和填充模型已生成的思维链，观察最终答案依赖，不声称直接读取了模型内部真实推理。

## 研究问题

模型先写推理、再输出答案，并不证明答案真的由这些文字得来。作者检查思维链是否只是事后解释，或者是否依赖读者看不懂的措辞信息，而不是把解题准确率提升直接当作解释可信。

证据：e1, e3

## 原有做法与缺口

已有工作能构造不忠实的例子，但还需要比较普通任务、不同模型和不同干预。论文采用多项互补测试，分别排查某类失败；通过其中一项不等于获得完整忠实性证明。

证据：e1, e5

## 核心方法

对同一问题生成思维链，再分别提前截断、在某一步加入错误、换成无信息省略号，或保持含义不变地改写。对前三类干预观察答案如何变化，对改写检查准确率是否保留。截断与加错曲线上方的面积 AOC 越大，表示模型越不容易保持原答案；主实验用经 RLHF 的175B模型，错误句由未做 RLHF 的预训练模型生成。

证据：e1, e2, e3

## 一个具体例子

AQuA 的电视题需要计算30%的人群中的24%，正确值为7.2%。作者把中间24%改成20%，再让模型续写；示例得到6%的推算，最后还选了最接近的错误选项。这个受控改变用于检查模型是否受推理影响，不是说加入错误后答错就证明原推理完整忠实。

证据：e3

## 输入与产出

输入是八类选择题、逐句拆开的模型推理和用于干预的生成器；还另有可控制难度的加法题。每道题采100条推理，温度0.8、nucleus p=0.95，之后通过答案选项的 token 概率评价。输出是准确率、与原答案相同的比例，以及加错和截断的 AOC。

证据：e1, e2, e3

## 关键结果与实验条件

表2中 AQuA 的提前回答 AOC 为0.44，加错 AOC 为0.52，准确率由约28%到43%；ARC Easy 的相应 AOC 仅0.02、0.07，准确率增益约0.77个百分点。HellaSwag 使用 CoT 的准确率反而下降约4.69个百分点，却不属于最不依赖推理的任务。13B模型在八项中的七项比175B更常因CoT改变答案。

证据：e3, e4

## 主要贡献

论文将思维链可靠性拆成可干预的问题，而非只比较有无 CoT 的成绩。空白填充没有带来同样收益，改写多数保留原有准确率；这些结果削弱了“只靠额外 token 计算”或“特定措辞藏信息”两种解释，并显示任务与模型能力需要一起考虑。

证据：e2, e3, e4

## 局限与适用边界

研究没有独立观察内部真实推理，所以“答案受干预影响”只是证据之一。模型也可能修复错误、忽略不合理干预，或采用论文没覆盖的机制。主要对象是当时的 RLHF 助手，不能将规模趋势直接套到所有现代推理模型，也不能把对措辞隐写未发现证据说成不可能存在隐写。

证据：e5

## 成本与复现条件

每题100条推理，再对多个截断位置、错误位置与改写版本继续生成，代价高于普通一次答题。需要模型采样和答案 token 概率；规模实验为节省计算，使用有无 CoT 的答案改变比例替代完整干预组。论文没有提供可通用到其他 API 的固定费用。

证据：e2, e4

## 与研究主题的关系

知识库分析：它是使用反思或推理文字诊断智能体时的重要边界材料。文字解释能提升成绩、影响后续答案和忠实反映内部过程是不同主张；本文没有验证解释驱动的 RSI。

研究关联分析；未作为论文结论。
