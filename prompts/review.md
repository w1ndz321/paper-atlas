# 收录前复核 · v1.7

重新对照原文与卡片，修正问题后再确认 review 字段。不以“章节齐全”替代内容准确。

1. **恢复理解**：只读 one_liner、method、trace，能否说清输入、执行过程、产出？是否只是把摘要换成中文？
2. **来源忠实**：逐项核对标题、作者、版本、关键数字和指标。摘录来自指定页吗？实验条件在同一句或同段保留了吗？相关证据真的支持结论吗？
3. **压缩损失**：有没有丢掉公式中的条件、反例、异常设置、预算或作者保留意见？收益和新增成本是否同时保留？
4. **评测设置**：任务数量、模型版本、工具权限、指标、预算和重复次数有没有混淆？RSI 的修改对象、固定组件及改进机制的证据是否清楚？可解释性是否区分相关、因果干预和解释忠实性？是否把未报告的检验写成已验证结论？
5. **公开内容边界**：内容是否只来自公开论文和官方项目？移除用户对话、私人计划和未发表观点；研究关联仅对应公开主题。
6. **作者与库的区分**：贡献是否属于作者？知识库相关性/推断是否明确标记？有没有暗示已人工实测或独立复现？
7. **入库一致性**：类型准确，主 Topic 与维度匹配，每个所属研究主题的三个维度均有受控标签，classification_reason 有实质依据；RSI 是否说明演化后的组件在下一轮的实际职责、固定部分及改进能力证据，是否把专项检验或任务分数上涨夸为改进能力增强；交叉 collections 有实际连接证据、没有混作主 Topic。方向之外的论文可归兴趣探索，未预设子类时允许 subtopics 留空，不虚构研究关联；完整卡片与证据要求不降低。关联论文真实存在、原文可追溯。全文不足时保留待处理任务。
8. **读起来是否自然**：把 one_liner、method 和 results 连起来读，能否听出作者具体做了什么、结果在什么条件下成立？把名词堆叠改成有主语、有动作的句子，拆开过长的句子，删掉空泛评价和重复的开场白。不要靠统一句式、口语填充词或比喻营造“人味”。
9. **改写是否丢信息**：逐节对照改写前的事实清单，确认模型、任务、数字、单位、比较对象、预算、因果方向与结论边界都还在。原文位置仍须支持对应句子，不能只因句子更顺就通过复核。
10. **两种语言是否一致**：逐节比对英文与已复核的中文，核对数字和限定条件，确认关联论文 id、证据 id 和页码一致。英文应自然连贯；缺少翻译的旧卡片会显示原文，不能把原文误标成已完成的英文版本。

复核完成后设 evidence_checked=true、compression_checked=true；它们代表 Codex 本轮复核完成，不代表独立专家验证或科学真实性保证。
